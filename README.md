#  GiftGenius - Android Application

Мобильное приложение для генерации идей подарков на основе предпочтений пользователя. Приложение использует алгоритмы машинного обучения (через backend) для подбора релевантных товаров с маркетплейсов Ozon и Wildberries.

## 📱 Описание

GiftGenius решает проблему выбора подарков, предлагая персонализированные рекомендации. Пользователь заполняет анкету (кому, повод, интересы, бюджет), а приложение генерирует список подходящих вариантов с прямыми ссылками на покупку.

### Ключевые возможности:
*   🧠 **Умная генерация**: Подбор подарков на основе введенных параметров.
*   ❤️ **Избранное**: Сохранение понравившихся идей в локальную базу данных (Room).
*   📡 **Офлайн-режим**: Просмотр ранее сохраненных подарков без интернета.
*   🛒 **Интеграция с маркетплейсами**: Прямые ссылки на товары.
*   🎨 **Material Design**: Современный и интуитивно понятный интерфейс.

## 🛠 Технологический стек

### Клиентская часть (Android)
*   **Язык**: Java
*   **Min SDK**: API 27 (Android 8.0 Oreo)
*   **Архитектура**: MVVM (Model-View-ViewModel)
*   **UI Toolkit**: ViewBinding, Material Components
*   **База данных**: Room (SQLite)
*   **Сеть**: Retrofit 2 + Gson
*   **Загрузка изображений**: Glide
*   **Асинхронность**: LiveData, Coroutines (через Retrofit)

### Серверная часть (Backend)
*   **Фреймворк**: FastAPI (Python)
*   **База данных**: PostgreSQL
*   **AI/ML**: Hugging Face Inference API
*   **Репозиторий Backend**: [GiftGenius-backend](https://github.com/VladTatyanin/GiftGenius-backend.git)

## 🚀 Установка и запуск

### Предварительные требования
1.  Установленный [Android Studio](https://developer.android.com/studio) (последняя стабильная версия).
2.  JDK 11 или выше.
3.  Запущенный backend сервер (см. раздел "Настройка Backend").

### Шаг 1: Клонирование репозитория
```bash
git clone https://github.com/VladTatyanin/GiftGenius-frontend.git
cd GiftGenius-frontend
```

### Шаг 2: Настройка Backend
Перед запуском Android-приложения необходимо запустить серверную часть.

1.  Клонируйте репозиторий бэкенда:
    ```bash
    git clone https://github.com/VladTatyanin/GiftGenius-backend.git
    cd GiftGenius-backend
    ```
2.  Установите зависимости Python:
    ```bash
    pip install -r requirements.txt
    ```
3.  Запустите сервер:
    ```bash
    uvicorn main:app --reload
    ```
    *Сервер будет доступен по адресу `http://127.0.0.1:8000`*

> **Важно:** В эмуляторе Android адрес `localhost` соответствует `10.0.2.2`. Убедитесь, что в файле `ApiClient.java` указан правильный IP-адрес, если вы запускаете приложение на физическом устройстве (используйте IP вашего компьютера в локальной сети).

### Шаг 3: Запуск Android приложения
1.  Откройте проект в Android Studio.
2.  Дождитесь синхронизации Gradle.
3.  Выберите устройство (эмулятор или физическое устройство).
4.  Нажмите **Run** (▶️) или используйте комбинацию `Shift + F10`.

## ⚙️ Конфигурация

### Сетевые запросы
Базовый URL API настроен в классе `ApiClient.java`:
```java
private static final String BASE_URL = "http://10.0.2.2:8000/"; // Для эмулятора
// private static final String BASE_URL = "http://192.168.1.XX:8000/"; // Для физического устройства
```

### Разрешения
В `AndroidManifest.xml` добавлены разрешения:
*   `INTERNET` - для доступа к API
*   `ACCESS_NETWORK_STATE` - для проверки подключения

## 🧪 Тестирование

### Основные сценарии проверки:
1.  **Генерация подарков**:
    *   Заполните все поля анкеты.
    *   Нажмите "Найти подарки".
    *   Убедитесь, что список загрузился корректно.
2.  **Избранное**:
    *   Нажмите на сердечко у любого подарка.
    *   Перейдите во вкладку "Избранное".
    *   Убедитесь, что подарок отображается.
    *   Удалите подарок из избранного и проверьте, что он исчез.
3.  **Офлайн-режим**:
    *   Отключите интернет на устройстве.
    *   Попробуйте сгенерировать новые подарки (должна появиться ошибка).
    *   Перейдите в "Избранное" (должны отображаться сохраненные ранее данные).

###  Возможные проблемы

**Проблема:** `ClearText traffic not permitted`
**Решение:** Убедитесь, что в `AndroidManifest.xml` есть атрибут `android:usesCleartextTraffic="true"` в теге `<application>`, так как локальный сервер работает по HTTP, а не HTTPS.

**Проблема:** `Connection refused`
**Решение:** Проверьте, что backend сервер запущен и доступен по указанному IP-адресу. Если используете эмулятор, адрес должен быть `10.0.2.2`.
